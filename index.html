Open Data

[09/2026] EgoAction: a real-world construction action recognition dataset built upon Ego4D. It focuses on fine-grained construction worker actions captured from an egocentric perspective.

[02/2026] ICON Pose: the first open dataset with 1,387 egocentric images and corresponding 2D construction worker poses across 63 action types.

[10/2025] ConstructionSite 10K: the first dataset containing 10k construction site images developed to test how vision language models (VLMs) can understand construction site images for image captioning, visual grounding, and safety rule violation VQA.

[06/2025] Indoor FireRescue Radar: the first 4D Indoor Millimeter Wave Dataset for Hazardous Environment Perception.
